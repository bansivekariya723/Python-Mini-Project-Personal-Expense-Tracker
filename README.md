# Personal Expense Tracker

## Name : Bansi Vekariya
## Enrollno. 12402080601016
A clean, lightweight desktop application built with Python using **Tkinter** and **SQLite3**.

## 📌 Features
- **Add Expense**: Enter Date, Category, Amount, and Description.
- **View Expenses**: Real-time table displaying all recorded expenses.
- **Delete Expense**: Select any record from the table and delete it.
- **Total Calculation**: Automatically computes and displays the sum total of all expenses.
- **Data Persistence**: Uses a local SQLite database (`expenses.db`), so data remains saved even after closing the app.

---

## 🚀 How to Run

1. Open your terminal or Command Prompt in this folder.
2. Run:
   ```bash
   python expense_tracker.py
   ```
